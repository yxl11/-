# 三机吊载动力学与基础控制实现说明

本文保留物理模型和历史基础控制的定义。当前默认控制已接入申请书 PDE 编队与反步边界方法，见 [PDE 实现说明](pde_method.md)；下文“基础控制”节不代表本次默认控制器。

## 坐标与状态

世界坐标z轴向上，机体系采用右手系，旋翼合推力沿机体正z轴。姿态矩阵R将机体坐标变换到世界坐标；四元数按w、x、y、z排列，角速度ω在机体系表达。本工程不是PX4的NED／FRD接口，后续接入时须显式转换。

负载编号0，无人机编号1至3。每个刚体状态为位置p、速度v、四元数q及角速度ω，共13个数；另有12个电机实际推力状态，总计64个数。四元数单位约束意味着独立状态维数少于存储维数。

## 物理方程

设q_i为从负载挂点指向无人机的缆绳单位方向，T_i为张力。符号q_i在本节表示绳方向，与程序的姿态四元数字段须区分。负载挂点在负载体坐标系为r_i，世界系力臂a_i=R_L r_i；无人机端暂位于其质心。

无人机平动满足

m_i p̈_i = f_i R_i e₃ − m_i g e₃ − T_i q_i − D_i v_i。

负载平动满足

m_L p̈_L = Σ T_i q_i − m_L g e₃ − D_L v_L + F_ext。

各无人机转动满足

I_i ω̇_i = τ_i − ω_i × (I_i ω_i) − D_ωi ω_i。

负载转动满足

I_L ω̇_L = Σ r_i × (R_Lᵀ T_i q_i) − ω_L × (I_L ω_L) − D_ωL ω_L。

惯量在机体系表达。默认使用均匀长方体惯量计算负载惯量，三机使用给定对角惯量。

四旋翼不是能直接施加任意空间力的质点。各机四电机推力f_j经分配矩阵生成合推力和力矩：

[f, τ_x, τ_y, τ_z]ᵀ = B [f_1, f_2, f_3, f_4]ᵀ。

B的各行依次为1、旋翼位置y、旋翼位置−x和带旋转方向符号的反扭矩系数。电机输入先经过0至单电机最大推力的限幅，实际推力按一阶模型变化：ḟ_j=(f_j,cmd−f_j)/τ_m。该模型以推力为电机状态，未单独求转速或电池电气动态。

## 绳索约束和张力

定义d_i=p_i−p_L−R_L r_i，长度ℓ_i=‖d_i‖，绳方向q_i=d_i/ℓ_i。定长约束为

g_i = (d_iᵀd_i−l_i²)/2 = 0。

相对速度u_i=v_i−v_L−Ω_L×a_i，其中Ω_L=R_Lω_L。先在不施加缆绳张力的情况下计算各刚体的自由加速度与自由角加速度，记挂点到无人机的自由相对加速度为b_i。它包含负载挂点的切向与向心加速度。

令h_i=r_i×(R_Lᵀq_i)，则每个积分子步求解3×3对称正定线性系统

A T = b，

A_ij = δ_ij/m_i + q_iᵀq_j/m_L + h_iᵀ I_L⁻¹ h_j，

b_i = q_iᵀb_i,free + ‖u_i‖²/ℓ_i + 2ζω_c q_iᵀu_i + ω_c²g_i/ℓ_i。

最后两项为Baumgarte稳定化，用于抑制数值绳长漂移，其目标是g̈+2ζω_c ġ+ω_c²g=0。它们不是弹性缆绳的刚度与阻尼。结果中同时输出绳长残差和约束功率，以检查数值稳定化的影响。

求出T后，将等大反向作用力施加于无人机和负载，同时将对应挂点力矩施加于负载。负载运动完全来自这些力与力矩；程序不把参考轨迹直接赋给负载。

本版只实现绷紧模式。在任何RK4子步若求得明显负张力，会抛出ModelDomainError，保存可用日志并报告失败；不会使用负张力，也不会简单截断后继续假定绳长固定。接近零张力和松绳后的混合动态属于未来扩展。

## 基础控制

每架无人机的参考位置由负载参考和固定标称构型偏置组成。参考是名义几何构型，负载可以在物理模型中偏离它。

位置层以50 Hz更新期望合推力向量：

F_i,d = (m_i+m_L,nom/3)(a_ref+g e₃) + H_i − m_i[K_p(p_i−p_i,ref)+K_d(v_i−v_ref)]。

H_i为对称悬停构型的水平内拉力补偿，H_i=(m_L,nom g/3)tan(α)e_radial,i。它不是张力传感器反馈，也不保证动态张力永远均匀。

姿态层以250 Hz更新。期望机体z轴沿F_i,d，期望航向固定。采用几何姿态误差e_R=vee(R_dᵀR−RᵀR_d)/2，以及比例和角速度阻尼力矩，再补偿ω×Iω。总推力命令取F_i,d在当前机体z轴上的投影。通过B⁻¹分配到四电机，逐电机限幅。

本版省略期望角速度及其导数前馈，属于基础姿态PD，不宣称复现文献控制器全部项或其完整稳定性结论。物理积分为500 Hz四阶Runge Kutta；电机命令在姿态更新间隔内保持。每步归一化四元数，绳长不进行人为位置投影。

基础控制器不使用负载状态，因此接近未来实机按参考轨迹执行的控制结构，但它不是PX4源码或已辨识PX4闭环模型。后续必须开展控制环节辨识或PX4在环验证。

## 验证与证据

单元物理检查包括：

- 对称悬停时T=m_Lg/(3cosα)，状态导数接近零。
- 缆绳内力和内力矩不改变系统总线动量、总角动量的外力平衡。
- 绳索初始速度满足切向约束时，加速度级约束成立，约束瞬时功率接近零。
- 超出绷紧模式时退出，而不是允许缆绳受压。
- 四元数／旋转矩阵一致，四电机输出满足推力界限。
- 修改负载真值而保持无人机状态不变，不改变基础控制器输出。

积分验证使用悬停、初始3°负载倾斜和2 N横向平滑脉冲，比较2 ms与1 ms结果，并保留4 ms结果检查收敛趋势。这里的步长比较保持控制频率和记录时刻不变，避免把控制采样差异混入积分误差。

输出中的RMSE是三维位置误差范数的均方根。负载倾角是其正z轴与世界竖直轴的夹角，不包含偏航；绳方向偏差相对标称20°悬停绳方向计算。三绳张力变化率由50 Hz记录数据差分计算，峰值、最小距离和其他状态极值也标明为50 Hz采样结果。负张力检查发生在所有RK4子步。

## 文献定位

缆绳正张力约束及刚性负载联合动力学可与[Sreenath与Kumar的多机吊载研究](https://hybrid-robotics.berkeley.edu/publications/RSS2013.pdf)对照；四旋翼姿态与位置控制结构参考[Lee等人的几何控制研究](https://mathweb.ucsd.edu/~mleok/pdf/LeLeMc2010_quadrotor.pdf)。本工程采用自编约束力求解和简化基础控制，用于建立可检查的实验基座，不直接继承上述文献的全部理论保证。
