# 申请书 PDE 编队方法的三机仿真实现

版本说明：本文记录此前 PDE 单层实现。当前已加入申请书第 2.3(3) 节的外层观测、合力预测、力分配与动态构型逆映射，见 [合力预测与逆映射方法](force_prediction_mapping.md)。PDE 本层继续使用无人机状态，新增研究外层另外使用理想模拟负载状态和绳力测量；本文旧状态不代表当前整个工程。

本版实现申请书第 2.3(1) 节的反应—扩散—对流 PDE 与反步边界控制，对应式 (1)、(6)—(9)。用三架实际无人机作为三个拓扑节点，以真实模拟状态计算空间差分和边界积分，再通过速度、姿态和电机环驱动三机刚性吊载物理模型。运行结果见 [PDE 仿真报告](../results/PDE方法仿真报告.md)。本次只运行该方法，不进行算法性能对照。

这是基于申请书公式、补全运输参考和飞行接口后的三节点工程实现。它不等于完整研究项目的复现，也不代表已证明三机非线性吊载系统具有原文宣称的全局指数稳定性。申请书其他章节的故障/时延观测、ESO、Tube MPC、力分配优化、学习避障未接入本次运行。

## 2 拓扑坐标与运输参考

用 ξ 区分拓扑坐标与物理世界的 x 坐标。三机分别处于

\[
\xi_0=0,\quad\xi_1=\alpha/2,\quad\xi_2=\alpha,\qquad\alpha=1.
\]

1 号机为锚点，2 号机为跟随者，3 号机为右边界领导者。“锚点”是移动的编队边界角色，并非固定在地面的锚固装置。三机在真实空间保持三角形布局，通信链按 1—2—3 编号，与一条抽象参数曲线上的采样相容。

令参考分布为

\[
\bar w(\xi,t)=p_{L,d}(t)+r(\xi),\qquad
r(\xi_i)=r_i^{\rm anchor}+l_iq_i^0.
\]

`r(ξ)` 可取经过三机名义偏置的二次 Lagrange 插值；程序仅使用三个真实节点，不需要增加隐藏的虚拟无人机。该曲线不代表实体绳索，也不宣称点间曲率已被三机精确分辨。

参考提升后的控制模型是

\[
w_t=\nu(w_{\xi\xi}+2bw_\xi+\lambda w)+f_{\rm ref},\qquad
f_{\rm ref}=\bar w_t-\nu(\bar w_{\xi\xi}+2b\bar w_\xi+\lambda\bar w).
\]

因此误差 `e=w−w̄` 满足设计方程

\[
e_t=\nu(e_{\xi\xi}+2be_\xi+\lambda e),\qquad
e_t(0)=-\nu c e(0).
\]

程序在误差坐标中直接计算上述式子，与在绝对坐标中加入离散参考提升项相等；不会用 λ 乘上绝对世界位置，避免控制输出随地图原点任意变化。ν 是物理秒与无量纲 PDE 时间之间的统一尺度，所有 PDE 系数同步缩放。

## 3 反步核与边界控制

先用 `q(ξ,t)=exp(bξ)e(ξ,t)` 消去对流项，得到

\[
q_t=\nu[q_{\xi\xi}+(\lambda-b^2)q].
\]

按申请书式 (6)—(7)，定义

\[
z(\xi,t)=q(\xi,t)-\int_0^\xi k(\xi,\eta)q(\eta,t)\,d\eta,
\]

\[
\sigma=\mu+\lambda-b^2,\qquad
k(\xi,\eta)=-\sigma\eta
\frac{I_1\!\left(\sqrt{\sigma(\xi^2-\eta^2)}\right)}
{\sqrt{\sigma(\xi^2-\eta^2)}}.
\]

实现允许 σ≥0，并通过收敛幂级数求值，保留解析极限

\[
k(\xi,0)=0,\qquad k(\xi,\xi)=-\sigma\xi/2.
\]

对于齐次左边界，标准目标系统为 `z_t=ν(z_ξξ−μz)`。本版左端允许非零初始锚点误差并按 ODE 衰减，变换后还存在由锚点误差驱动的项，不能直接套用齐次边界结论。

右端 `z(α,t)=0` 对应

\[
U(t)=\bar w(\alpha,t)+
\int_0^\alpha k(\alpha,\eta)e^{b(\eta-\alpha)}e(\eta,t)\,d\eta.
\]

三节点间距 h=α/2，使用左矩形求积：

\[
K_j=h\,k(\alpha,\xi_j)e^{b(\xi_j-\alpha)},\quad j=0,1,
\qquad U_d=\bar p_2+K_0e_0+K_1e_1.
\]

该求积排除右端未知值，避免把领导者输入自己代入积分形成未处理的代数环。N=3 时只有一个内部跟随者，且 k(α,0)=0，故锚点在积分中的直接权重为零，它通过跟随者差分项间接影响领导者。

## 4 PDE 到三架四旋翼的执行过程

内部节点的速度修正为

\[
\phi_1=\nu\left[
\frac{e_0-2e_1+e_2}{h^2}
+b\frac{e_2-e_0}{h}+\lambda e_1\right],\qquad
\phi_0=-\nu c e_0.
\]

定义边界残差 `B=e₂−K₀e₀−K₁e₁`。使用节点当前测得的误差速度，实现右端动态边界：

\[
\phi_2=K_0\dot e_0+K_1\dot e_1-k_BB,\qquad
v_{i,c}=\dot p_{L,d}+\phi_i.
\]

在理想速度执行器下该式使 `Ḃ=−k_BB`。物理仿真中则通过有限带宽的速度环逐渐跟随：

\[
a_{i,c}=\ddot p_{L,d}+k_v(v_{i,c}-v_i),
\]

\[
F_{i,d}=m_i a_{i,c}+\frac{m_{L,nom}}3\ddot p_{L,d}
+(m_i+m_{L,nom}/3)g e_3+H_i.
\]

`H_i` 是名义悬停水平绳力前馈。速度和加速度指令分别做向量范数限幅，再交给几何姿态环和四电机分配。负载惯量只通过名义前馈参与；实际张力、负载位置与姿态来自牛顿–欧拉约束动力学，不回填参考轨迹。

`PDEController` 继承旧类仅复用姿态和电机分配；它重写了整个位置更新函数，不调用旧的独立位置 PD。跟随者必须使用邻居误差，领导者必须使用核积分与邻居速度。控制器不读取负载真值或动力学求解出的张力。

程序同时记录 `ė₁−φ₁` 作为内部节点的 PDE 实现残差。该残差包含物理速度环、姿态响应和吊索耦合等影响；它非零时，不能声称真实刚体运动严格满足理想一阶 PDE。

## 5 本次参数与任务

参数集中在 `configs/pde.json`，以下均为仿真设计值：

| 参数 | 数值 | 含义 |
| --- | --- | --- |
| α | 1 | 无量纲拓扑域长度 |
| b | 0.2 | 对流系数的一半 |
| λ | 1 | 反应系数 |
| μ | 2 | 反步目标衰减参数 |
| ν | 0.15 s⁻¹ | PDE 时间尺度 |
| c | 6.6667 | 锚点增益，使 νc=1 s⁻¹ |
| k_B | 1 s⁻¹ | 边界位置残差伺服增益 |
| k_v | 4.5 s⁻¹ | 速度跟随增益 |
| 速度指令上限 | 0.8 m/s | 各机速度向量范数 |
| 加速度指令上限 | 1.0 m/s² | 各机加速度向量范数 |
| 位置/PDE 更新 | 50 Hz | 实际状态驱动的离散控制 |
| 姿态更新 / 物理积分 | 250 / 500 Hz | 保留原物理模型实现 |

σ=2.96，边界权重为 `[0, −0.4366963553]`。理想三节点一阶闭环矩阵特征值约为 `−1.33822, −1, −1`；它只检查这个理想离散设计，不是三机非线性系统的稳定性证明。

主工况 `pde_transport` 从已经悬空的绷紧构型开始：整体初始偏移 `[0.08, −0.06, 0] m`，负载初始绕 y 轴倾斜 2°。无人机端点随负载挂点调整，使初始绳长仍精确成立，电机初值保持名义悬停值。这样能观察非零边界反馈及编队误差的消退。

随后执行 8 秒初始保持、40 秒 S 形去程、8 秒保持、40 秒返程、8 秒末段保持，总计 104 秒。没有额外风力输入。负载位置由物理方程演化，不因参考进入保持段而被强制停止。

物理参数沿用 3 kg 总悬吊负载、每机假设质量 2.5 kg、每机假设最大总推力 65 N、绳长 1.8 m。场地为 20×10×5 m。承载、惯量、阻尼及飞控带宽尚未按实机标定。
