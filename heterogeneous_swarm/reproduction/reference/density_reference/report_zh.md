# 固定Gaussian KDE的目标IID采样量级参照

本计算仅使用既有任务参数、shape_state及0.5 s指标时钟，没有生成随机样本，也没有运行控制器或新增运动仿真。

在每个时刻，假设N个成员位置独立服从当前目标Gaussian。期望误差可严格分解为核平滑偏差平方和有限样本方差；这不是实际受控成员误差的分解。

固定翼量级说明：
- sweep_regrouping：既有P固定翼Lrho=6.780309；IID期望参照=8.257440；固定对角自核项=8.335030。
- patrol：既有P固定翼Lrho=6.725977；IID期望参照=8.257305；固定对角自核项=8.335030。

固定翼目标三轴乘积13×9×3.5=409.5 m³，N=10、beta=1.7 m，故固定对角自核项为409.5/(10×1.7³)。任务的水平面积保持变形及旋转不改变该项。它解释为何这一归一化指标包含较大的离散核贡献，但不能说6.7全部来自自核项；总量还含成员间重叠、与目标的交叉项及目标平方范数。

实际受控点集可能比目标IID样本更规则且具有相关性，其Lrho低于IID期望并不矛盾，也不据此给方法重新排名。不能从实测Lrho减去IID方差后称为控制误差。目标核平滑偏差也不等于全部实际形状误差。
